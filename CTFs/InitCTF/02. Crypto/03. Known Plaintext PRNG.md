# Known Plaintext PRNG

**Category:** Crypto · **Points:** 200 · **Challenge ID:** 14

**Brief:** Flag XORed in 4-byte blocks. Key advances via LCG. Start key secret, but flag format gives first 4 plaintext bytes.

**Steps:**

1. `encrypt.py`: random 32-bit key. Each chunk: `chunk ^ key`, then `key = (key * 1103515245 + 12345) & 0xFFFFFFFF`.
2. Plaintext starts `InIt`. XOR with first 4 ciphertext bytes → initial key.
3. Re-run generator, decrypt every block:

   ```python
   from pathlib import Path

   c = Path("flag.enc").read_bytes()
   key = int.from_bytes(c[:4], "big") ^ int.from_bytes(b"InIt", "big")

   def nxt(k):
       return (k * 1103515245 + 12345) & 0xFFFFFFFF

   out = bytearray()
   for off in range(0, len(c), 4):
       chunk = c[off:off+4]
       n = len(chunk)
       ci = int.from_bytes(chunk.ljust(4, b"\0"), "big")
       out += (ci ^ key).to_bytes(4, "big")[:n]
       key = nxt(key)

   print(out)
   ```

   Output: `InIt{kn0wn_pl41nt3xt_4tt4cks_4r3_c00l}`

**Flag:** `InIt{kn0wn_pl41nt3xt_4tt4cks_4r3_c00l}`

**Takeaway:** Known 4-byte prefix recovers whole stream. LCG state predictable once known.
