# The Careless Twins

**Category:** Crypto · **Points:** 200 · **Challenge ID:** 16

**Brief:** Two RSA moduli, one ciphertext. Same syndicate, same `p`.

**Steps:**

1. `encryption.py` reuses `p`:

   ```python
   p  = getPrime(1024)
   q1 = getPrime(1024); n1 = p * q1
   q2 = getPrime(1024); n2 = p * q2
   ```

   `random.seed(1337)` in `get_secure_prime()` is a decoy. Real bug is shared `p`.

2. GCD gives `p`. Then `q1`, then `d`, then decrypt `c1`:

   ```python
   from math import gcd
   from Crypto.Util.number import long_to_bytes, inverse

   p = gcd(n1, n2)
   q1 = n1 // p
   d = inverse(e, (p-1)*(q1-1))
   print(long_to_bytes(pow(c1, d, n1)))
   ```

**Flag:** `InIt{n3v3r_r3us3_pr1m3s_1n_rs4}`

**Takeaway:** Shared prime falls to one GCD. Seeded PRNG is a red herring here.
