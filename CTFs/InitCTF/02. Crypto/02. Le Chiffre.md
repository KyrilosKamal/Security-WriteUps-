**Category:** Crypto · **Points:** 200 · **Challenge ID:** 6

**Brief:** `UvLg{d1m3u3k3_i4a_q0g_bn3_4uli3z}`. Note: "The key is the hour when everything goes quiet."

**Steps:**

1. Quiet hour = midnight. Key = `midnight`.
2. Vigenère decrypt, digits pass through, key only advances on letters:

```python
def vdec(ct, key):
    out, i = [], 0
    for c in ct:
        if c.isalpha():
            k = ord(key[i % len(key)].lower()) - 97
            b = ord(c.lower()) - 97
            p = (b - k) % 26
            out.append(chr(p + (65 if c.isupper() else 97)))
            i += 1
        else:
            out.append(c)
    return ''.join(out)

print(vdec("UvLg{d1m3u3k3_i4a_q0g_bn3_4uli3z}", "midnight"))
```
