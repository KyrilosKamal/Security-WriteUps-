# ec2-dropper

**Category:** Forensics · **Points:** 200 · **Challenge ID:** 8

**Brief:** `/opt/agent/vault.py` decrypts local vault. Key derived from EC2 instance ID. Recover operator note.

**Steps:**

1. Key: `sha256("s4lt_" + instance_id)`. Blob: `IV || AES-CBC(ct)`, PKCS#7. Normally instance ID comes from IMDS.
2. Instance ID not in script. Found in cloud-init log: `i-0a1b2c3d4e5f67890`.
3. Decrypt:

   ```python
   import hashlib
   from Crypto.Cipher import AES

   iid = "i-0a1b2c3d4e5f67890"
   blob = open("vault.bin", "rb").read()
   iv, ct = blob[:16], blob[16:]
   key = hashlib.sha256(("s4lt_" + iid).encode()).digest()
   pt = AES.new(key, AES.MODE_CBC, iv).decrypt(ct)
   pt = pt[:-pt[-1]]
   print(pt.decode())
   ```

   Output:

   ```json
   {"config_version": 2, "collected_region": "ap-south-1",
    "operator_note": "InIt{imds_k3y3d_s3cr3t_v4ult}"}
   ```

**Flag:** `InIt{imds_k3y3d_s3cr3t_v4ult}`

**Takeaway:** Key only as secret as instance ID. Algorithm and salt were in script; missing input was in cloud-init log.
