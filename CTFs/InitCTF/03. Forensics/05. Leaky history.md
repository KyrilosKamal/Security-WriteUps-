# leaky history

**Category:** Forensics / Git · **Target:** `tanvoro-deploy` repo tarball

**Flag:** `InIt{d4ngl1ng_c0mm1t_l34k}`

**Recon:** The archive holds a small Flask app and a deploy script. `README.md` says secrets come from the CI vault. `.gitignore` excludes `deploy/secrets.env`, and `deploy.sh` loads that file in CI. The working tree and `main` contain no secrets file, so the flag is not in the normal tree.

**History:** `git log --all -p` shows nothing flag-shaped on reachable commits. `git fsck --lost-found --unreachable` reports an unreachable commit and blob, and `.git/ORIG_HEAD` points to that commit. Someone reset or amended the branch, and the old commit stayed in the object store.

**Dropped commit:** `6dfa863` by Dana Okoro, "ci: wire up deploy secrets." It adds `deploy/secrets.env` and deletes `.gitignore`, `.env.example`, and the README notes from `main`. The secret was reachable only through this commit.

**Leaked file:** `git cat-file -p 4d080a7` returns:

```dotenv
# DO NOT COMMIT -- loaded by CI
AWS_ACCESS_KEY_ID=AKIAZZ7FAKE4EXAMPLE1
AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
DEPLOY_TOKEN=InIt{d4ngl1ng_c0mm1t_l34k}
DB_PASSWORD=pr0d-db-9f3a21
```

The `DEPLOY_TOKEN` value is the flag. The AWS values use AWS documentation placeholder formats and are not live credentials.

**Root cause:** A secret was committed, then dropped from the branch. Dropped commits remain in the object store until garbage collection prunes them. `.gitignore` only stops files that are never staged. A file committed before the rule existed, or added with `git add -f`, stays tracked.

**Takeaway:** When something seems removed from a repo, check `git fsck --unreachable` and `ORIG_HEAD` first.

**Real-world follow-up:**

1. Rotate every credential in the file, even if the values look like placeholders.
2. Rewrite history with `git filter-repo` or BFG, then force-push.
3. Expire reflogs and run `git gc --prune=now` on any server copies.
4. Add a pre-commit secret scanner such as gitleaks or trufflehog.
