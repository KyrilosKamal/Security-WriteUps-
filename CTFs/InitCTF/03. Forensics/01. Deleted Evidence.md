# deleted evidence

**Category:** Forensics · **Points:** 100 · **Challenge ID:** 7

**Brief:** Seized disk image. Intruder deleted files before cable pulled. Recover them.

**Steps:**

1. MBR disk, NTFS partition at sector 2048:

   ```bash
   mmls evidence.img
   # 002:  000:000   0000002048   0000024575   NTFS / exFAT (0x07)
   ```

2. `fls -r -o 2048` shows deleted entry (leading `*`):

   ```
   +++ -/r * 75-128-2:  recovery_code.gz
   ```

3. Extract by inode, decompress:

   ```bash
   icat -o 2048 evidence.img 75 > recovery_code.gz
   zcat recovery_code.gz
   # VaVg{q3y3g3q_ohg_a0g_t0a3}
   ```

4. Content is ROT13:

   ```bash
   zcat recovery_code.gz | tr 'A-Za-z' 'N-ZA-Mn-za-m'
   # InIt{d3l3t3d_but_n0t_g0n3}
   ```

**Flag:** `InIt{d3l3t3d_but_n0t_g0n3}`

**Takeaway:** `fls`/`icat` recover deleted NTFS files via MFT. "Deleted" holds only until clusters get reused. ROT13 was the extra layer.
