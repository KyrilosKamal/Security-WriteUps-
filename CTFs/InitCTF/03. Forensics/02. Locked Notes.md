# Locked Notes

**Category:** Forensics · **Points:** 100 · **Challenge ID:** 11

**Brief:** Android Secure Notes app data. Looked locked on device. Data extracted clean.

**Steps:**

1. Archive contents: `notes.db`, `shared_prefs/…_preferences.xml`, `onboarding_seen`, `image_cache.tmp`, `logcat.txt`.
2. Prefs hold decoy `last_backup_token` (base64) → `larkfield-session-not-the-flag`.
3. Note `_id=4` ("Recovery Code") body starts `1f 8b`, gzip:

   ```bash
   sqlite3 notes.db "select hex(body) from notes where _id=4;"
   ```

4. Decompress:

   ```python
   import sqlite3, gzip
   b = sqlite3.connect("notes.db").execute(
       "select body from notes where _id=4").fetchone()[0]
   print(gzip.decompress(b))
   ```

**Flag:** `InIt{s3cur3_n0t3s_n0t_s0_s3cur3}`

**Takeaway:** "Locked" was a UI flag (`is_locked=1`), not encryption. Body was plain gzip. Backup token was a decoy.
