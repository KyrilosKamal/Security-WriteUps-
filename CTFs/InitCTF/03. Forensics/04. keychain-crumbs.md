# keychain-crumbs

**Category:** Forensics · **Points:** 200 · **Challenge ID:** 9

**Brief:** macOS infostealer sent data over plaintext HTTP. Rebuild archive, recover leaked secret.

**Steps:**

1. HTTP JSON POSTs to `update.icloud-sync.cc/api/collect`. 58 requests, each a chunk:

   ```bash
   tshark -r capture.pcap -q -z io,phs
   tshark -r capture.pcap -Y 'http.request.method=="POST"' \
          -T fields -e http.file_data
   ```

2. Reassemble by `id`, join base64 `part` values, decode:

   ```python
   import subprocess, json, base64

   out = subprocess.run(["tshark","-r","capture.pcap",
       "-Y",'http.request.method=="POST"',
       "-T","fields","-e","http.file_data"],
       capture_output=True, text=True).stdout

   parts = {}
   for line in out.splitlines():
       if not line.strip():
           continue
       d = json.loads(bytes.fromhex(line).decode())
       parts[int(d["id"])] = d["part"]

   blob = "".join(parts[i] for i in sorted(parts))
   open("exfil.bin","wb").write(base64.b64decode(blob))
   ```

   `exfil.bin` is a ZIP.

3. Archive has `system_profiler.txt`, `Safari/browsing_data.json`, `TCC.db`, a Finder plist, and `Library/Keychains/keychain_dump.txt`.

4. `backup-key` generic password in keychain dump is base64:

   ```text
   "SW5JdHtrM3ljaDRpbl9jcnVtYnNfbDM0azNkXzB2M3JfcGw0MW5faHR0cH0="
   ```

   Decodes to flag.

**Flag:** `InIt{k3ych4in_crumbs_l34k3d_0v3r_pl41n_http}`

**Takeaway:** Chunked HTTP exfil easy to reassemble. Hidden secret was one more base64 layer inside stolen keychain.
