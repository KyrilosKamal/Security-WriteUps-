# The Troll's Ticket

**Category:** Misc · **Points:** 200 · **Challenge ID:** 21

**Flag:** `InIt{j0urney_4cr0ss_1ndia}`

**Brief:** A tampered Indian Railways ticket. The route runs Delhi, Mumbai, Chennai, Kolkata.

**Steps:**

1. The original `challenge.zip` was an empty placeholder. The author replaced it mid-event with `challenge_1.zip`, and new solves appeared on the board afterward. Re-fetching `/api/v1/challenges/21` returned the current file URL.
2. Extract the outer archive. It holds `README.txt`, `outer_wordlist.txt`, and `IRCTC_Tatkal_Hack.pdf`. The "PDF" is actually a ZipCrypto archive.
3. Crack it with the wordlist. A one-byte header check gives false positives, so confirm each candidate with the CRC or a full decompression. The password is `railwaystationroyaljourney`.
4. The unzipped contents give the next password, `cholebhature`, which opens `mumbai.jpg` and `mumbai_wordlist.txt`.
5. Use `vada_pav` to open `chennai.jpg` and `chennai_wordlist.txt`.
6. Use `mylapore` to open `kolkata.jpg`.
7. `kolkata.jpg` has a tar archive appended at offset `0x2686F`. Carve it out:

   ```bash
   binwalk kolkata.jpg
   dd if=kolkata.jpg bs=1 skip=157807 of=kolkata.tar
   tar -xvf kolkata.tar
   # kolkata.txt, final_list.txt, golden_diamond_ticket_locked.pdf
   ```

8. The PDF is AES-encrypted. `final_list.txt` holds a 20-word list, and the password is `peacock`:

   ```bash
   pdftotext -upw peacock golden_diamond_ticket_locked.pdf -
   ```

   The e-ticket text ends with the flag.

**Takeaway:** Each stage was a nested archive with the next wordlist inside. Verify ZipCrypto candidates with the CRC, not just the header byte. The mid-event file swap caused most of the confusion.
