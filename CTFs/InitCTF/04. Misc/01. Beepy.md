# Beepy

**Category:** Misc · **Points:** 100 · **Challenge ID:** 12

**Flag:** `InIt{B33PY_M0RS3_1S_C00L}`

**Recon:** WAV file, 8 kHz mono, about 18.5 s. Signal is clean on/off keying, no stego layers.

**Decode:**

1. Build a 10 ms envelope: max absolute sample per window.
2. Threshold the envelope into on/off runs.
3. Map run lengths to Morse. Short on = dot, long on = dash. Short off = symbol gap, long off = letter/word gap.
4. Decoded Morse:

   ```text
   -... ...-- ...-- .--. -.-- ..--.- -- ----- .-. ... ...-- ..--.- .---- ... ..--.- -.-. ----- ----- .-..
   ```

5. Map with the ITU Morse table. `..--.-` is underscore, so the word breaks are underscores.

**Takeaway:** Classic Morse over audio. Envelope detection plus the ITU table is enough. No extra steganography.
