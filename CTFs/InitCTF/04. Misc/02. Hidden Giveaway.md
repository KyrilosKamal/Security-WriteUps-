## Reconnaissance

The challenge supplied a PNG image described as a tourist map of India. The hint suggested that information was hidden in plain sight.

## Blue-channel LSB extraction

The blue channel's least-significant bit (LSB) plane was extracted and converted into a black-and-white image:

```python
from PIL import Image
import numpy as np
import zxingcpp

image = np.asarray(
    Image.open("india_tourist_map.png").convert("RGB")
)

blue_lsb = ((image[:, :, 2] & 1) * 255).astype("uint8")
plane = Image.fromarray(blue_lsb)

results = zxingcpp.read_barcodes(plane)
for result in results:
    print(result.text)
```
